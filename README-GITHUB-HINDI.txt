GITHUB UPLOAD
1. Download and unzip this package.
2. Open your GitHub repository.
3. Upload the contents of the folder moulana-aktar-ali-website (not the outer ZIP folder).
4. Keep the folder structure unchanged, especially assets/ and assets/images/.
5. Commit changes. Vercel will redeploy if the repository is connected.

The site is static HTML/CSS/JavaScript and does not require a build command. Set the Vercel output directory to the repository root.

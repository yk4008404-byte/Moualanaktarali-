MOULANA AKTAR ALI WEBSITE - GITHUB PAGES

FILES: index.html, four service pages, about-moulana-aktar-ali.html,
testimonials.html, assets/style.css, assets/script.js, sitemap.xml, robots.txt.

PUBLISH:
1. Create a GitHub repository.
2. Upload all files and the assets folder, preserving folder structure.
3. Open Settings > Pages.
4. Choose Deploy from a branch > main > /(root) > Save.
5. Wait for GitHub Pages to publish.

BEFORE PUBLISHING:
- Replace stock photos with images you own or have permission to use.
- Add your genuine biography, credentials and verified experience.
- The certificate upload control previews a file locally only. To display it to every visitor, upload the certificate image into the repository and change the About page to use that image path.
- Replace testimonial placeholders only with genuine reviews shared with permission.
- Update zero-valued statistics only with verified figures.
- Replace YOUR-DOMAIN.example in sitemap.xml and robots.txt after you know your public site URL.
- Add Google Search Console after launch.

This is a static HTML website. It has no admin panel, database or server-side upload system.
